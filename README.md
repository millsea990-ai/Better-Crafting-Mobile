# Better Crafting Mobile Advanced 🌟

**نسخة مخصصة لـ Stardew Valley على الموبايل (Android)**  
مصمم بواسطة **Grok 4.20 + Benjamin ابن يعقوب** لمستخدم millsea990-ai

### المميزات الكاملة:
- بحث فوري (🔍 ابحث هنا)
- نظام مفضلة (نجمة تحفظ في الـ save)
- Bulk Crafting: x5, x10, x25, x50, x100, Max
- أزرار كبيرة مناسبة للـ Touch
- يعمل مع Crafting Page + Workbench + Cooking
- متوافق مع SMAPI Android 4.3.2.1

### طريقة التثبيت:
1. حمل أحدث DLL من **GitHub Actions** (شوف أسفل).
2. انقل الملف `BetterCraftingMobile.dll` إلى مجلد الـ Mods في SMAPI Android:
   - عادة: `/storage/emulated/0/Android/data/com.chucklefish.stardewvalley/files/SMAPI/mods/BetterCraftingMobile/`
3. شغل اللعبة → SMAPI → المود يشتغل تلقائي.
